# TECHNOVA — College Festival Website

TECHNOVA is a modern, responsive college festival website designed with a dark and premium visual style, featuring black and purple backgrounds, neon accents, and engaging animations.

## Project Name
**TECHNOVA**

## Technologies Used
- HTML5 — Website structure
- CSS3 — Styling, responsive layouts, and animations
- Vanilla JavaScript — Interactive features and functionality

## Features
- Premium dark theme with neon effects
- Animated hero section
- Interactive event cards
- Event search and category filters
- Festival schedule with day-wise tabs
- Event registration form with validation
- Event details popup
- Organizer dashboard
- CSV export for demo registrations
- Responsive layout for desktop and mobile devices

## Project Structure

```text
TECHNOVA/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run the Project

1. Download or clone the project repository.
2. Open the `TECHNOVA` folder in Visual Studio Code.
3. Ensure all four files are in the same folder.
4. Open `index.html` in a web browser.
5. Alternatively, use the Live Server extension in VS Code.

## Registration System

The registration form validates user input and stores demo registrations in the browser's local storage. The organizer dashboard allows users to view saved registrations and export them as a CSV file.

**Note:** This is a frontend demonstration. Registration data is not sent to a server, and the organizer dashboard does not have authentication.

## Customization

You can customize the event names, dates, timings, venues, colors, and other website content by editing the relevant HTML, CSS, and JavaScript files.
